1  Mathematics and Programming Toolbox

1.1 Exponential series

The exponential function has the power-series expansion

\[ e^x = \sum_{k=0}^{\infty}\frac{x^k}{k!} = 1+x+\frac{x^2}{2!}+\frac{x^3}{3!}+\cdots. \]

Therefore, for any constant \(\lambda\),

\[ \sum_{k=0}^{\infty}\frac{\lambda^k}{k!} = e^\lambda. \]

1.2 Derivatives

1.2.1 Basic rules

For constants \(a\), \(c\) and differentiable functions \(f(x)\) and \(g(x)\),

\[ \frac{d}{dx}[c] = 0, \]

\[ \frac{d}{dx}[x^a] = ax^{a-1}, \]

\[ \frac{d}{dx}[cf(x)] = cf'(x), \]

\[ \frac{d}{dx}[f(x)+g(x)] = f'(x)+g'(x), \]

\[ \frac{d}{dx}[f(x)-g(x)] = f'(x)-g'(x). \]

1.2.2 Product rule

\[ \frac{d}{dx}[f(x)g(x)] = f'(x)g(x)+f(x)g'(x). \]

1.2.3 Quotient rule

\[ \frac{d}{dx} \left[ \frac{f(x)}{g(x)} \right] = \frac{ f'(x)g(x)-f(x)g'(x) }{ [g(x)]^2 }. \]

1.2.4 Chain rule

If

\[ y=f(g(x)), \]

then

\[ \frac{dy}{dx} = f'(g(x))g'(x). \]

Equivalently,

\[ \frac{d}{dx}f(g(x)) = f'(g(x))g'(x). \]

This is the rule used whenever a function appears inside another function.

Example

Consider

\[ y=(3x+2)^5. \]

This is a composition of two functions:

\[ f(x)=3x+2 \]

and

\[ g(u)=u^5. \]

Therefore,

\[ y=g(f(x)). \]

Using the chain rule,

\[ \frac{dy}{dx} = g'(f(x))f'(x). \]

Since

\[ g'(u)=5u^4 \]

and

\[ f'(x)=3, \]

we obtain

\[ \frac{dy}{dx} = 5(3x+2)^4 \cdot 3 = 15(3x+2)^4. \]

1.2.5 Powers of functions

\[ \frac{d}{dx}[f(x)]^a = a[f(x)]^{a-1}f'(x). \]

In particular,

\[ \frac{d}{dx}\sqrt{f(x)} = \frac{f'(x)}{2\sqrt{f(x)}}. \]

and

\[ \frac{d}{dx}\frac{1}{f(x)} = -\frac{f'(x)}{[f(x)]^2}. \]

1.2.6 Exponential functions

\[ \frac{d}{dx}e^x=e^x. \]

More generally,

\[ \boxed{ \frac{d}{dx}e^{f(x)} = e^{f(x)}f'(x) } \]

by the chain rule.

For a constant \(a>0\),

\[ \frac{d}{dx}a^x = a^x\ln(a), \]

and

\[ \frac{d}{dx}a^{f(x)} = a^{f(x)}\ln(a)\,f'(x). \]

1.2.7 Logarithms

\[ \frac{d}{dx}\ln x = \frac{1}{x}. \]

More generally,

\[ \boxed{ \frac{d}{dx}\ln[f(x)] = \frac{f'(x)}{f(x)} } \]

provided \(f(x)>0\).

For logarithms with base \(a\),

\[ \frac{d}{dx}\log_a x = \frac{1}{x\ln(a)}, \]

and

\[ \frac{d}{dx}\log_a[f(x)] = \frac{f'(x)}{f(x)\ln(a)}. \]

1.2.8 Trigonometric functions

\[ \frac{d}{dx}\sin x=\cos x, \]

\[ \frac{d}{dx}\cos x=-\sin x, \]

\[ \frac{d}{dx}\tan x=\sec^2 x. \]

With an inner function \(f(x)\),

\[ \frac{d}{dx}\sin[f(x)] = \cos[f(x)]f'(x), \]

\[ \frac{d}{dx}\cos[f(x)] = -\sin[f(x)]f'(x), \]

\[ \frac{d}{dx}\tan[f(x)] = \sec^2[f(x)]f'(x). \]

Also,

\[ \frac{d}{dx}\sec x = \sec x\tan x, \]

\[ \frac{d}{dx}\csc x = -\csc x\cot x, \]

\[ \frac{d}{dx}\cot x = -\csc^2 x. \]

1.2.9 Inverse trigonometric functions

\[ \frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1-x^2}}, \]

\[ \frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1-x^2}}, \]

\[ \frac{d}{dx}\arctan x = \frac{1}{1+x^2}. \]

With an inner function \(f(x)\),

\[ \frac{d}{dx}\arcsin[f(x)] = \frac{f'(x)} {\sqrt{1-[f(x)]^2}}, \]

\[ \frac{d}{dx}\arccos[f(x)] = -\frac{f'(x)} {\sqrt{1-[f(x)]^2}}, \]

\[ \frac{d}{dx}\arctan[f(x)] = \frac{f'(x)} {1+[f(x)]^2}. \]

1.3 Integrals and primitives

A function \(F(x)\) is a primitive or antiderivative of \(f(x)\) if

\[ F'(x)=f(x). \]

The indefinite integral represents the family of all primitives of \(f(x)\):

\[ \int f(x)\,dx = F(x)+C, \]

where \(C\) is an arbitrary constant.

1.3.1 Basic rules

For constants \(a\), \(c\) and integrable functions \(f(x)\) and \(g(x)\),

\[ \int c\,dx = cx+C, \]

\[ \int cf(x)\,dx = c\int f(x)\,dx, \]

\[ \int [f(x)+g(x)]\,dx = \int f(x)\,dx + \int g(x)\,dx, \]

and

\[ \int [f(x)-g(x)]\,dx = \int f(x)\,dx - \int g(x)\,dx. \]

1.3.2 Power functions

For \(a\neq -1\),

\[ \int x^a\,dx = \frac{x^{a+1}}{a+1}+C. \]

More generally,

\[ \boxed{ \int [f(x)]^a f'(x)\,dx = \frac{[f(x)]^{a+1}}{a+1}+C } \]

for \(a\neq -1\).

In particular,

\[ \int f(x)f'(x)\,dx = \frac{[f(x)]^2}{2}+C. \]

For \(a=-1\),

\[ \int \frac{1}{x}\,dx = \ln|x|+C. \]

More generally,

\[ \boxed{ \int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)|+C. } \]

1.3.3 Exponential functions

\[ \int e^x\,dx = e^x+C. \]

More generally,

\[ \boxed{ \int e^{f(x)}f'(x)\,dx = e^{f(x)}+C. } \]

For example,

\[ \int e^{3x+2}\,dx = \frac{1}{3}e^{3x+2}+C. \]

For a constant \(a>0\),

\[ \int a^x\,dx = \frac{a^x}{\ln(a)}+C. \]

More generally,

\[ \boxed{ \int a^{f(x)}f'(x)\,dx = \frac{a^{f(x)}}{\ln(a)}+C. } \]

A particularly useful form is

\[ \int e^{-\lambda x}\,dx = -\frac{1}{\lambda}e^{-\lambda x}+C, \qquad \lambda\neq0. \]

1.3.4 Logarithms

\[ \int \ln x\,dx = x\ln x-x+C, \qquad x>0. \]

Also,

\[ \boxed{ \int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)|+C. } \]

For example,

\[ \int \frac{2x}{x^2+1}\,dx = \ln(x^2+1)+C. \]

1.3.5 Trigonometric functions

\[ \int \sin x\,dx = -\cos x+C, \]

\[ \int \cos x\,dx = \sin x+C, \]

\[ \int \sec^2 x\,dx = \tan x+C. \]

With an inner function \(f(x)\),

\[ \boxed{ \int \sin[f(x)]f'(x)\,dx = -\cos[f(x)]+C, } \]

\[ \boxed{ \int \cos[f(x)]f'(x)\,dx = \sin[f(x)]+C, } \]

and

\[ \boxed{ \int \sec^2[f(x)]f'(x)\,dx = \tan[f(x)]+C. } \]

Also,

\[ \int \csc^2[f(x)]f'(x)\,dx = -\cot[f(x)]+C, \]

\[ \int \sec[f(x)]\tan[f(x)]f'(x)\,dx = \sec[f(x)]+C, \]

and

\[ \int \csc[f(x)]\cot[f(x)]f'(x)\,dx = -\csc[f(x)]+C. \]

1.3.6 Inverse trigonometric forms

\[ \int \frac{1}{1+x^2}\,dx = \arctan x+C, \]

and more generally,

\[ \boxed{ \int \frac{f'(x)} {1+[f(x)]^2} \,dx = \arctan[f(x)]+C. } \]

Also,

\[ \int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x+C, \]

and more generally,

\[ \boxed{ \int \frac{f'(x)} {\sqrt{1-[f(x)]^2}} \,dx = \arcsin[f(x)]+C. } \]

1.3.7 Substitution rule

Substitution is the integral counterpart of the chain rule.

If

\[ u=f(x), \]

then

\[ du=f'(x)\,dx. \]

Therefore,

\[ \boxed{ \int g(f(x))f'(x)\,dx = \int g(u)\,du. } \]

If \(G'(u)=g(u)\), then

\[ \boxed{ \int g(f(x))f'(x)\,dx = G(f(x))+C. } \]

Example

Consider

\[ \int 2x e^{x^2}\,dx. \]

Let

\[ u=x^2. \]

Then

\[ du=2x\,dx. \]

Therefore,

\[ \begin{aligned} \int 2x e^{x^2}\,dx &= \int e^u\,du \\ &= e^u+C \\ &= e^{x^2}+C. \end{aligned} \]

1.3.8 Integration by parts

Integration by parts is the integral counterpart of the product rule:

\[ \boxed{ \int u\,dv = uv-\int v\,du. } \]

If

\[ u=f(x) \]

and

\[ dv=g'(x)\,dx, \]

then

\[ du=f'(x)\,dx \]

and

\[ v=g(x). \]

Therefore,

\[ \boxed{ \int f(x)g'(x)\,dx = f(x)g(x) - \int f'(x)g(x)\,dx. } \]

Example

Consider

\[ \int xe^x\,dx. \]

Take

\[ u=x, \qquad dv=e^x\,dx. \]

Then

\[ du=dx, \qquad v=e^x. \]

Therefore,

\[ \begin{aligned} \int xe^x\,dx &= xe^x-\int e^x\,dx \\ &= xe^x-e^x+C \\ &= e^x(x-1)+C. \end{aligned} \]

1.3.9 Definite integrals

If

\[ F'(x)=f(x), \]

then the Fundamental Theorem of Calculus gives

\[ \boxed{ \int_a^b f(x)\,dx = F(b)-F(a). } \]

Equivalently,

\[ \int_a^b f(x)\,dx = \left[ F(x) \right]_a^b. \]

The basic properties are

\[ \int_a^b f(x)\,dx = -\int_b^a f(x)\,dx, \]

\[ \int_a^a f(x)\,dx = 0, \]

and

\[ \int_a^b f(x)\,dx + \int_b^c f(x)\,dx = \int_a^c f(x)\,dx. \]

1.3.10 Substitution in definite integrals

If

\[ u=f(x), \]

then the limits must also be transformed:

\[ x=a \Rightarrow u=f(a), \]

and

\[ x=b \Rightarrow u=f(b). \]

Thus,

\[ \boxed{ \int_a^b g(f(x))f'(x)\,dx = \int_{f(a)}^{f(b)}g(u)\,du. } \]

1.3.11 Integration by parts for definite integrals

\[ \boxed{ \int_a^b f(x)g'(x)\,dx = \left[ f(x)g(x) \right]_a^b - \int_a^b f'(x)g(x)\,dx. } \]

1.3.12 Improper integrals

An integral over an infinite interval is defined using a limit:

\[ \int_a^\infty f(x)\,dx = \lim_{b\to\infty} \int_a^b f(x)\,dx. \]

Similarly,

\[ \int_{-\infty}^b f(x)\,dx = \lim_{a\to-\infty} \int_a^b f(x)\,dx. \]

For the entire real line,

\[ \int_{-\infty}^{\infty}f(x)\,dx = \int_{-\infty}^{c}f(x)\,dx + \int_c^{\infty}f(x)\,dx, \]

provided both integrals converge.

For example, if \(\lambda>0\),

\[ \begin{aligned} \int_0^\infty e^{-\lambda x}\,dx &= \lim_{b\to\infty} \left[ -\frac{1}{\lambda}e^{-\lambda x} \right]_0^b \\ &= \frac{1}{\lambda}. \end{aligned} \]

Therefore,

\[ \boxed{ \int_0^\infty \lambda e^{-\lambda x}\,dx = 1. } \]
